## ✨ Features

- Responsive, single-page design with smooth scroll navigation
- Animated hero section with typing effect ([Typed.js](https://github.com/mattboldt/typed.js/))
- Scroll-triggered animations ([GSAP](https://gsap.com/) + ScrollTrigger)
- Interactive tilt effect on project cards ([Vanilla-Tilt.js](https://micku7zu.github.io/vanilla-tilt.js/))
- Project showcase with live demo / GitHub links and tech stack badges
- Working contact form powered by [Formspree](https://formspree.io/)

## 🛠️ Built With

## 🚀 Getting Started (Run Locally)

This is a static site — no build step required.

```bash
# Clone the repo
git clone https://github.com/suraj62838/<your-repo-name>.git
cd <your-repo-name>

# Just open index.html in your browser
open index.html   # macOS
# or
start index.html  # Windows
```

Or serve it locally:

```bash
npx serve .
```

## ☁️ Deployment

This site is deployed on **Vercel**.

```bash
npm install -g vercel
vercel --prod
```

Alternatively, connect this GitHub repo to Vercel from the [Vercel dashboard](https://vercel.com/new) for automatic deploys on every push.
